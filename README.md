# Rep Sheet

A small gym website that shows what to lift during your session.

- **Workout plan:** pick Full body, Push / Pull / Legs, or Upper / Lower and follow each day's exercises, with sets × reps, rest time and a rough session length.
- **By muscle group:** browse exercises for chest, back, legs, shoulders, arms and core, each with a form tip.
- **Three styles:** Iron Plate, Chalkboard and Clean Studio, switchable from the top bar.

## Run it

Open `index.html` in a browser. No build step.

## Edit it

| File | What it controls |
| --- | --- |
| `data.js` | Exercises, sets, reps, rest and the workout plans |
| `styles/themes.css` | Colors and fonts for each style |
| `styles/base.css` | Layout shared by all styles |
| `app.js` | Page logic |
